# 西太子堂から地球を掘ろう！ Webサイト

「西太子堂から地球を掘ろう！」穴掘りイベントの告知・案内用Webサイトです。

単なるイベント情報の掲載ではなく、空き地を子どもたちの冒険の入口にするワクワク感、地域の温かさ、親子で外遊びを楽しむ空気感を伝えることを目的にしています。

## イベント概要

- イベント名：西太子堂から地球を掘ろう！
- 開催日：6月28日（土）
- 時間：11:00〜15:00
- 場所：西太子堂駅南側の空き地
- 住所：太子堂4-9-8
- 主催：そとあそびプロジェクト・せたがや
- 持ち物：スコップ、飲みもの、タオル、汚れてもよい服装、帽子、必要に応じて軍手

## 技術構成

- Next.js
- TypeScript
- Tailwind CSS
- Static Export
- Cloudflare Pages 想定

## 開発コマンド

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

Cloudflare Pages では、ビルドコマンドを `npm run build`、出力ディレクトリを `out` に設定する想定です。

## 構成

```text
app/
  globals.css
  layout.tsx
  page.tsx
data/
  event.ts
```

イベント情報は `data/event.ts` に構造化してあります。今後、イベント一覧、申込管理、写真管理、Supabase連携へ拡張しやすいようにしています。

## デザイン方針

- スマホファースト
- 青空、土、草、宝探しの色
- 子どもが読みやすい大きめの文字
- 手作り感と冒険感
- 金属探知機、宝探し、土の断面を連想させる表現
